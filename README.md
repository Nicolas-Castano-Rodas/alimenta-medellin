# ALIMENTA

### La comida merece una segunda oportunidad.

ALIMENTA es una plataforma tecnológica que conecta supermercados, restaurantes, panaderías, tiendas y productores con consumidores y fundaciones para aprovechar alimentos excedentes en Medellín, Colombia.

## Objetivo

Reducir el desperdicio de alimentos, facilitar el acceso a productos a menor precio y promover la donación responsable mediante tecnología, geolocalización y análisis inteligente.

## Funcionalidades principales

- Marketplace de alimentos excedentes.
- Publicación y gestión de inventarios.
- Descuentos y reservas de productos.
- Donaciones a fundaciones verificadas.
- Geolocalización y puntos de recogida.
- Gestión de pedidos y trazabilidad.
- Paneles para comercios y organizaciones.
- Analítica e inteligencia artificial.
- Administración y verificación de establecimientos.

## Arquitectura tecnológica

ALIMENTA se desarrollará inicialmente como un monolito modular organizado en un monorepo.

| Componente | Tecnología |
|---|---|
| Frontend | Next.js, React y TypeScript |
| Backend | NestJS y Node.js |
| Base de datos | PostgreSQL y PostGIS |
| ORM | Prisma |
| Inteligencia artificial | Python y FastAPI |
| Interfaz | Tailwind CSS y shadcn/ui |
| Monorepo | pnpm y Turborepo |
| Infraestructura | Docker |

## Mercado inicial

Medellín, Antioquia, Colombia.

## Principios del proyecto

- Seguridad y trazabilidad alimentaria.
- Protección de datos personales.
- Transparencia en las donaciones.
- Responsabilidad de los establecimientos.
- Tecnología orientada al impacto social y económico.

La inteligencia artificial será una herramienta de apoyo y no sustituirá los controles sanitarios ni certificará la inocuidad de los alimentos.
